# v0.2 导出前端代码（实现契约）

v0.2 在 v0.1 的读取/写入之上增加 `figma_export`：把 Figma 节点树变成可落盘的前端代码。

## 1. 工具面

```js
figma_export({
  format: 'html' | 'jsx' | 'svg' | 'json' | 'tokens',
  target?: 'selection' | 'page' | 'node',  // 默认 selection
  nodeIds?: string[],                      // target:'node' 必填；其他 target 可覆盖选区
  outDir?: string,                         // 默认 <cwd>/figma-export/<root>-<timestamp>/
})
```

返回：

```js
{
  ok: true,
  format: 'html',
  target: 'selection',
  outDir: '/Users/.../figma-export/pricing-desktop-20261112-213000',
  rootName: 'Pricing / Desktop',
  nodeCount: 29,
  files: [{ name: 'index.html', path: '.../index.html', bytes: 12345 }],
  counts: { frames, texts, leaves },
  warnings: [],
  treeStats: { count, truncated, maxNodes, depth }
}
```

只返回文件路径与摘要，不把整份代码塞回模型上下文。

## 2. 数据链路

```
figma_export
  → bridge command `tree`
      companion/code.js: serializeExportNode() 递归投影
      { id,name,type,x,y,width,height,visible,opacity,rotation,
        fills,strokes,strokeWeight,cornerRadius,effects,layout,clipsContent,
        text?, children? }
  → lib/export.js
      toHTML() / toJSX() / toJSON()
  → Host 写文件
```

`svg` 格式不走 `tree` 的代码生成：先 `tree` 拿根节点 id，再调用 companion 的 `export`（Figma 原生 `exportAsync({format:'SVG'})`）写 `.svg`。

## 3. 代码生成规则

| Figma | 生成 |
|---|---|
| Auto Layout HORIZONTAL / VERTICAL | `display:flex` + `flex-direction` + `gap` + `padding` + `justify-content` / `align-items` |
| 普通 Frame 的子节点 | `position:absolute; left; top`（相对于父 Frame） |
| 多根节点 / page | 自动包一层 `.figma-page`，按包围盒归一化坐标 |
| fills（SOLID） | 背景色；文字节点转为 `color` |
| strokes / strokeWeight | `border` |
| cornerRadius | `border-radius`（支持四角数组） |
| effects DROP_SHADOW / INNER_SHADOW | `box-shadow` |
| TEXT | 字体、字号、字重、行高、字距、对齐、大小写、装饰、`white-space:pre-wrap` |
| rotation | `transform: rotate()` |
| clipsContent | `overflow:hidden` |
| 渐变 / IMAGE fill | 保留 JSON、写 warnings，HTML/JSX 暂不内嵌 |
| VECTOR / BOOLEAN_OPERATION 等 | 保留占位盒子 + warning；建议用 `svg` 格式 |

产物：

- `html`：单个 `index.html`（内联 CSS，可直接双击）。
- `jsx`：`App.jsx` + `styles.css`（class 与 CSS 对应）。
- `svg`：每个根节点一个 `<name>-<id>.svg`。
- `json`：`design.json`，含完整节点树与元信息。

## 4. 测试

`tests/export.test.mjs` 覆盖 HTML/JSX/JSON、Escaping、Auto Layout、绝对定位、多根归一化、VECTOR warning；`tests/companion.test.mjs` 覆盖 `tree` 命令；`tests/tools.test.mjs` 覆盖 `figma_export` 四种格式与非法参数。

```bash
node --test tests/*.test.mjs
```

## 5. 已知限制

- HTML/JSX 是静态视觉还原，不生成交互逻辑。
- 渐变、图片填充、VECTOR 图标尚未内嵌；VECTOR 用 SVG 格式。
- 组件/变量/样式仍按展开后的图层树导出，不恢复组件抽象。
- 节点树上限 1200 节点；超出会截断并在 `warnings` 中说明。

## 6. 真机验收（2026-11-12）

| 目标 | 格式 | 结果 |
|---|---|---|
| `Pricing / Desktop` 5:2（29 节点） | html | `figma-export/pricing/index.html`，headless Chrome 渲染与 Figma 截图对照一致 |
| 同上 | jsx | `figma-export/pricing-jsx/App.jsx` + `styles.css` |
| 同上 | svg | `figma-export/pricing-svg/pricing-desktop-5-2.svg`（Figma 原生矢量，390KB） |
| 同上 | json | `figma-export/pricing-json/design.json`（41KB） |
| `Login / Mobile` 1:2（24 节点） | html | `figma-export/login/index.html`，橙色主色/间距与 Figma 一致 |
| Page 1（登录 + 定价，53 节点） | html | `figma-export/page/index.html`，多根节点按 Figma 坐标归一化 |

真机验证中修复了一个导出保真问题：Figma 自动宽度文本（如 `PRO`）按固定 px 宽在浏览器里会折行，已对 `textAutoResize:'WIDTH_AND_HEIGHT'` 输出 `width:max-content; height:auto`。

测试：`node --test tests/*.test.mjs` → 101/101 通过。
