# v0.4.2 — figma_designer_compare

把 2–6 个候选 Figma 节点截图，生成自包含方向对比页。

## 工具

```js
figma_designer_compare({
  title: '登录页 — 三个方向',
  candidates: [
    { nodeId: '11:606', name: 'Acme workspace', concept: '安静、编辑式、左对齐', palette: ['#0B1020', '#F97316'], traits: ['单列', '编辑式'] },
    { nodeId: '12:100', name: 'Editorial', concept: '大字标题，强品牌', palette: ['#F8FAFC', '#F97316'], traits: ['对比强', '大标题'] }
  ]
})
```

## 输入

- `candidates`: 2–6 个 `{ nodeId, name?, concept?, palette?, traits? }`
- `title?`: 对比页标题，默认「设计方向对比」
- `scale?`: 截图倍率 0.25–2，默认 1
- `outDir?`: 输出目录，默认 `<工作目录>/figma-export/compare-<时间戳>/`

## 产物

```text
<outDir>/
  compare.html     自包含 HTML 对比页
  manifest.json    候选元数据（不含 base64 图）
  01-<slug>.png
  02-<slug>.png
```

对比页：

- 中性外壳，不带风格倾向；
- 每张卡片：截图、编号、名称、概念、色板、特征；
- “选这个”复制 `选 01 <名称>`；
- “实际尺寸”新窗口打开原图；
- 响应式，窄屏单列。

## 边界

- 只读：不修改 Figma；
- 只截候选首屏/代表页，不铺完整多页；
- 不替代独立评审；
- 截图是静态图，不判断动效；
- 如果候选是隐藏图层，截图可能为空/不可见，先确认 visible。
