# v0.4.0 设计质量层

目标：把 Figma 插件从“能改画布”推进到“能按设计标准判断、约束和验收”。

## 新增 Skill：figma-design

与 `figma-designer` 分工：

- `figma-designer`：操作层，负责读/写/截图/设计系统/导出；
- `figma-design`：判断层，负责方向、视觉语言、证据、独立评审。

主流程：

1. 事实与范围；
2. 方向卡（`DESIGN.md`）：北极星、主角/主动作、调性、字体、色彩、间距、骨架、记忆点；
3. 灰度结构；
4. 设计系统与视觉；
5. 真实截图证据（目标视口、480px 三秒测试、200% 关键区域）；
6. 独立评审（1–10 分、问题清单、保留项）；
7. 交付说明。

## 边界

- v0.4.0 不新增画布工具，复用现有 Figma 工具；
- 不做自动生图/图片填充（v0.4.x 后续）；
- 不做自动对比页/客观 lint（后续 `figma_designer_compare` / `figma_designer_audit`）；
- 动效只能在 Figma 有实际证据时评审，不凭静态图宣称通过。

## 实测（2026-11-16）

对当前 `Login / Mobile`（390×844）截图派独立评审，得到 **6/10**：

- 方向（深色 + 橙色单主操作）成立；
- 但首屏骨架仍是通用深色 SaaS 登录模板，触发“换掉产品名仍成立”否决；
- 主要问题：品牌/标题区模板、OAuth 无标识、控件高度不统一、密码态难辨、链接/法务可读性不足。

说明评审协议能发现真实问题；具体记录见任务目录 `.review/login-2026-11-16-review.md`（不随插件发布）。
