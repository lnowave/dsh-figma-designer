# v0.3 设计系统（组件 / 样式 / Variables）

v0.3 让 AI 不只是画图层，而是能读取和复用 Figma 里的设计系统对象。

## 1. 工具面

| 工具 | 作用 |
|---|---|
| `figma_designer_library` | 列出组件、组件集、Paint/Text/Effect/Grid 样式、Variable 集合与变量；支持 `kind`/`query`/`limit` |
| `figma_designer_instantiate` | 用 `componentId` 或 `componentName` 创建 Instance；组件集可用 `variant` 选变体；`overrides` 改实例内文字/填充/可见性/圆角/尺寸 |
| `figma_designer_style` | `apply` 把样式应用到节点的 fill/stroke/text/effect；`create` 新建 paint/text/effect 样式 |
| `figma_designer_variable` | `list` / `create` / `set` / `bind`；bind 支持 fill、stroke、padding*、itemSpacing、cornerRadius、width、height、opacity 等字段 |
| `figma_designer_apply`（扩展） | `create` 新增 `type:'component'`，可直接创建组件主文件 |

## 2. 数据与命令

```
figma_designer_library  → bridge command `library`
figma_designer_instantiate → `instantiate`
figma_designer_style    → `styles` (action: apply|create)
figma_designer_variable → `variables` (action: list|create|set|bind)
```

Figma 动态页面（`documentAccess: dynamic-page`）约束：

- 样式必须用 `setFillStyleIdAsync` / `setStrokeStyleIdAsync` / `setTextStyleIdAsync` / `setEffectStyleIdAsync`，不能同步赋值；
- 组件/样式/变量读取使用 async getter（`getLocalComponentsAsync`、`getLocalPaintStylesAsync`、`figma.variables.getLocalVariablesAsync`）；
- 创建变量时 `createVariable` 接收 **collection 节点**，不是 collection id；
- 改实例文字前必须 `figma.loadFontAsync`。

## 3. 典型用法

```js
// 1. 看设计系统
figma_designer_library({ kind: 'all' })

// 2. 用现有按钮组件
figma_designer_instantiate({
  componentName: 'Button / Primary',
  parentId: '5:66',
  width: 456,
  overrides: [{ nodeName: 'Label', text: 'Continue with email' }],
})

// 3. 应用样式
figma_designer_style({ action: 'apply', nodeId: '5:67', styleName: 'Heading / XL', target: 'text' })

// 4. 建 token 并绑定
figma_designer_variable({ action: 'create', name: 'color/primary', resolvedType: 'COLOR', value: '#F97316' })
figma_designer_variable({ action: 'bind', name: 'color/primary', nodeId: '5:64', field: 'fill' })
```

## 4. 真机验收记录

在 `Untitled` 文件里建立：

- Variables 集合 `Design Tokens`：`color/primary` = `#F97316`，`space/16` = 16；
- Paint Style `Brand / Primary`、Text Style `Heading / XL`；
- Component `Button / Primary`（220×48，Auto Layout，填充绑定 `color/primary`，`itemSpacing` 绑定 `space/16`）；
- 新建 `Design System Demo` 画板，实例化 `Primary CTA`，override 文案为 `Continue with email`。

已验证：`figma_designer_library` 能列出以上对象；`figma_designer_variable create/bind` 成功；`figma_designer_instantiate` 成功创建实例并改文字/宽度；`figma_designer_style apply` 能按样式值应用（Paint/Text）。

**样式链接限制**：Figma 的异步 `set*StyleIdAsync` 在本机 Figma 构建上会等待后端 10 秒并返回 `Unable to establish connection`，因此 `figma_designer_style apply` 默认走 value 模式（把样式值写入节点），可选 `link:true` 尝试链接但本机不可用。变量绑定（`figma_designer_variable bind`）和组件实例不受影响。

## 5. 已知限制

- 组件集变体目前按 `variantProperties` 精确匹配；复杂变体/组件属性（text/boolean/instance-swap）尚未覆盖。
- Variables 绑定目前支持常用字段；绑定失败会返回 `unsupported`，不会静默忽略。
- 样式应用会替换节点的 fill/stroke 等字段；应用前建议先用 `figma_designer_read` 确认目标。
- 导出的 HTML/JSX 目前仍是展开后的图层；token/组件抽象导出在 v0.3 后续或 v0.4。

## 6. v0.3.1 增量验收

- **组件集/变体**：基于 `Button / Primary` 克隆生成 `Button / Variants`（5:79），含 `Size=Small/State=Default`、`Size=Large/State=Default`、`Size=Small/State=Hover` 三个变体；`figma_designer_library` 正确列出组件集、变体属性与默认值。
- **变体实例**：`figma_designer_instantiate({componentName:'Button / Variants', variant:{Size:'Large',State:'Default'}})` 成功创建 `Variant CTA`（5:80），并覆盖文案为 `Instantiated Large`。
- **样式链接**：`figma_designer_style apply` 默认链接 style id 成功（内部先 `loadAllPagesAsync()`；这是 10 秒连接错误的根因）。`link:false` 可退回按值写入。
- **Token 导出**：`figma_designer_export({format:'tokens'})` 生成 `tokens.json` / `tokens.css` / `tokens.js`，包含 `color.primary`、`space.16`、`typography.heading.xl`、`paint.brand.primary`。
- 测试：`node --test tests/*.test.mjs` → **107/107** 通过。
