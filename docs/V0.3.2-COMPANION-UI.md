# v0.3.2 伴生插件窗口 UI

目标：窗口尽量小，不遮挡 Figma 设计；默认只显示连接状态、文件名/页面名和一行提示。

## 布局

- 窗口尺寸：折叠 **300×112**；展开日志 **300×330**（通过 `figma.ui.resize` 动态切换）。
- 顶部：状态圆点 + `已连接 / 未连接 / 连接中… / 执行中…`；右侧仅一个 `↻` 图标按钮（重新连接）。
- 中部：`文件名 / 页面名` 一行，超长省略，hover 显示完整名称。
- 底部：`› 日志` 切换 + `保持打开即可` 提示。
- 日志默认折叠；点击后展开日志区，底部显示 `端口 3977` 和 `清空` 按钮。
- 不再显示插件标题和版本号。

## 交互细节

- 日志展开/折叠会向主线程发送 `{type:'resize', width, height}`，code.js 校验范围后调用 `figma.ui.resize`。
- 连接状态只保留简短文案；具体错误/端口/命令仍在日志里。
- 日志最多保留 80 行，展开时自动滚到底部。

## 验证

- 单测：`node --test tests/*.test.mjs` → 108/108。
- `companion.test.mjs` 覆盖 `showUI` 尺寸与 resize 消息的范围裁剪。
- 折叠/展开布局已用静态预览 + Figma 真机窗口检查。
