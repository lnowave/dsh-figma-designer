## 2. Ops DSL v1

`figma_apply({ ops, dryRun?, operationId?, atomic? })`。ops 按顺序执行；每条 op 独立报告结果。

颜色统一用十六进制字符串：`"#RGB" | "#RRGGBB" | "#RRGGBBAA"`，或 `null` 表示无填充。`opacity` 0–1。坐标/尺寸为数字（px）。

### 2.1 公共节点字段（create 可用，update 的 patch 可用）

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | string | 图层名 |
| `x` / `y` | number | 位置；`parentId` 是 Frame 时为相对父级坐标，是 Page 时绝对坐标 |
| `width` / `height` | number | 尺寸（>=1） |
| `fill` | color \| null | 纯色填充 |
| `stroke` | color \| null | 纯色描边 |
| `strokeWidth` | number | 描边宽度（0 表示无描边） |
| `radius` | number \| [number,number,number,number] | 圆角；数组顺序 `[topLeft, topRight, bottomRight, bottomLeft]` |
| `opacity` | number | 0–1 |
| `visible` | boolean | 显隐 |
| `locked` | boolean | 锁定 |
| `rotation` | number | 角度（度） |
| `layout` | object \| null | Auto Layout：`{ mode:'HORIZONTAL'\|'VERTICAL', itemSpacing?, padding?:number\|{top,right,bottom,left}, primaryAxisAlign?:'MIN'\|'CENTER'\|'MAX'\|'SPACE_BETWEEN', counterAxisAlign?:'MIN'\|'CENTER'\|'MAX', wrap?:'NO_WRAP'\|'WRAP' }`；`null` 表示设为 `NONE` |
| `text` | object | 仅 text 节点：`{ characters, font?:{family,style}, fontSize?, align?:'LEFT'\|'CENTER'\|'RIGHT'\|'JUSTIFIED', lineHeight?:number\|{unit:'PIXELS'\|'PERCENT',value}, letterSpacing?:number\|{unit:'PIXELS'\|'PERCENT',value}, textAutoResize?:'NONE'\|'WIDTH_AND_HEIGHT'\|'HEIGHT' }` |
| `svg` | string | 仅 `svg` 类型：自包含 SVG 源码（create 用） |
| `effects` | array | `[{type:'DROP_SHADOW'\|'INNER_SHADOW'\|'LAYER_BLUR'\|'BACKGROUND_BLUR', color?, offset?:{x,y}, radius?, spread?, visible?}]` |

### 2.2 Op 列表

```js
{ op:'create', parentId?, type:'frame'|'rect'|'ellipse'|'text'|'line'|'polygon'|'star'|'svg',
  ...公共字段, children?:[createOp...] }
// 返回 nodeId；children 递归创建，坐标相对该节点
{ op:'update', nodeId:string, patch:公共字段子集 }
{ op:'move', nodeId, parentId, index? }        // 重新挂父级；坐标按新父级解释（v0.1 不换算）
{ op:'reorder', nodeId, index:number }          // 在父级 children 中重新排序
{ op:'clone', nodeId, parentId?, x?, y?, deep?:boolean }  // clone 默认深拷贝
{ op:'group', nodeIds:[string], name? }         // 必须同一父级；返回 groupId
{ op:'delete', nodeId }
{ op:'select', nodeIds:[string] }               // 设置当前选区
```

默认行为：`create` 未给 `parentId` 时挂到 **当前页面**；`create` 未给 `type` 报错。

### 2.3 结果

```js
// 成功
{ ok:true, dryRun:false, operationId:"...",
  applied:[{ opIndex, op, nodeId?, name?, type?, changes?:{...}, warning?:string }],
  created:[{ opIndex, nodeId, name, type }],
  updated:[{ opIndex, nodeId, name, changes:[fieldName...] }],
  deleted:[nodeId...],
  warnings:[string] }

// dryRun（不修改画布）
{ ok:true, dryRun:true, plan:{ willCreate:number, willUpdate:number, willDelete:number, willGroup:number, ops:[{opIndex, op, description}] }, warnings:[] }

// 失败
{ ok:false, error:{ code:'invalid-op'|'node-not-found'|'parent-not-found'|'unsupported'|'figma-error',
                    message, opIndex? }, applied:[...已成功部分...], uncertain?:true }
```

规则：
- 单条 op 失败时默认**停止后续 ops**（`atomic` 仍尽力回滚，见下），`applied` 保留已成功的部分。
- `atomic:true`：插件在内存记录已创建节点 id 与被修改节点的字段旧值；失败时删除已创建节点、恢复旧值；恢复失败时返回 `uncertain:true`。
- `operationId`：同一 id 重复提交直接返回首次结果（插件内存去重，保留最近 50 条），不重复执行。
- 字体：任何涉及 TEXT 的 create/update，先 `await figma.loadFontAsync({family,style})`；字体不存在时返回 `unsupported` 并列出 3 个可用字体候选（`figma.listAvailableFontsAsync`）。
- 颜色/圆角/布局等值在**插件侧**再做一次防御性校验，非法值返回 `invalid-op`。

## 3. 伴生插件命令协议

桥把命令以 `{id, command, args}` 长轮询下发；伴生插件（`companion/code.js`）执行后回 `{id, ok, value|error}`。

### 3.1 `ping`
args: `{}`。返回：
```js
{ ok:true, pluginVersion:'0.1.0', file, page, editorType, apiVersion,
  pages:[{id,name}], selectionCount, capabilities:{ svg:true, exportFormats:['PNG','SVG','PDF'], textEdit:true } }
```

### 3.2 `read`
args: `{ target?:'selection'|'page'|'node', nodeIds?:string[], depth?:number(0..6, 默认2),
         maxNodes?:number(1..300, 默认80), includeHidden?:boolean(默认false) }`
返回：
```js
{ ok:true, page:{id,name},
  target, nodes:[NodeSummary], stats:{ count, truncated:boolean, maxNodes, depth },
  selection:[nodeId...] }
```
`NodeSummary`：
```js
{ id, name, type, visible, locked, opacity, rotation,
  bounds:{x,y,width,height},                   // absoluteBoundingBox；无则用 x/y/width/height
  size:{width,height},                          // 仅当节点有 width/height
  children?:number,                             // 子节点数量
  childNodes?:[NodeSummary],                    // 当 depth>0 且未超 maxNodes
  fills?:[{type:'SOLID',color:'#RRGGBB',opacity}|{type:其它}] | null,
  strokes?:[...] | null, strokeWeight?:number,
  cornerRadius?:number | [number,number,number,number],
  layout?:{ mode, itemSpacing, padding:{top,right,bottom,left}, primaryAxisAlign, counterAxisAlign } | null,
  text?:{ characters, font:{family,style}, fontSize, align, lineHeight, letterSpacing, textAutoResize },
  component?:{ id, name } | null }              // 仅 INSTANCE
```
- 默认过滤 `visible=false` 的子节点（`includeHidden:true` 保留）。
- 达到 `maxNodes` 时停止展开，`stats.truncated=true`。
- `target:'selection'` 且无选区时返回空数组，不报错。
- 跨页：v0.1 `read` 只读当前页；`target:'node'` 支持任意已加载页面里的节点（用 `figma.getNodeByIdAsync`）。

### 3.3 `screenshot`
args: `{ nodeId?, scale?:number(0.1..4, 默认1) }`。nodeId 缺省 → 当前选区第一个节点；无节点返回 `no-node`。
返回：
```js
{ ok:true, node:{id,name,type}, scale,
  image:{ mimeType:'image/png', bytes:number, data:base64, width:number, height:number } }
```
（`width/height` 从 `exportAsync` 的 `constraint` 反推：`Math.round(node.width*scale)` 等；或直接用返回 PNG 尺寸不可得，用节点尺寸×scale 估算即可。）

> 这是桥的返回 value。工具层不得把 `data` 直接放进 content：`figma_screenshot` 必须先调用
> `ctx.get('attachments').saveImage({ data: Buffer.from(data,'base64'), mediaType })`，
> content 返回 `{type:'image', attachment:<ref>}`。原生工具返回
> `{type:'image', mimeType, data}` 会污染会话历史。

### 3.4 `apply`
args: `{ ops:[...], dryRun?:boolean, operationId?:string, atomic?:boolean }`，返回第 2.3 节结果。

### 3.5 `export`
args: `{ nodeIds:[string], format:'PNG'|'SVG'|'PDF', scale?:number(0.1..4, 默认1) }`
返回：
```js
{ ok:true, files:[{ nodeId, name, format, bytes, data:base64 }] }
```

### 3.6 `select`
args: `{ nodeIds:[string] }`。返回：`{ ok:true, selection:[nodeId...] }`。

## 4. Mock Figma 测试要求（companion-dev）

`tests/companion.test.mjs` 用 mock `figma` 评估真实 `companion/code.js`（`new Function('figma','__html__', src)`），至少覆盖：

1. `ping` 返回文件/页面/能力；
2. `read`：选区摘要、depth 展开、maxNodes 截断、隐藏节点过滤、文本/布局字段；
3. `screenshot`：base64 PNG、node 信息、无选区报 `no-node`；
4. `apply` create（frame + 嵌套文本，验证 appendChild/x/y/字体加载/fill 颜色转换）；
5. `apply` update（改 fill/layout/文本，验证旧值记录）；
6. `apply` dryRun 不创建节点（mock 记录 create 调用次数为 0）且返回 plan；
7. `apply` 单条失败返回 `applied` 前缀 + `error.opIndex`；
8. `apply` operationId 重复提交返回首次结果、不重复执行；
9. `apply` delete/group/clone/select 基本行为；
10. 非法 op（未知类型、缺 nodeId、颜色非法）返回 `invalid-op`。

## 5. Host 侧 ops 校验（ops-dev）

`lib/ops.js` 纯 ESM、零 import，导出：

```js
export const OP_TYPES = ['create','update','move','reorder','clone','group','delete','select']
export function validateOps(ops) -> { ok, errors:[{opIndex, code, message}], ops:normalizedOps }
export function summarizePlan(ops) -> { willCreate, willUpdate, willDelete, willGroup, ops:[{opIndex,op,description}] }
export function normalizeColor(value) -> { r,g,b,a } | null      // 支持 #RGB/#RRGGBB/#RRGGBBAA，非法返回 undefined
export function normalizePadding(value) -> {top,right,bottom,left} | null
export function clonePatch(patch) -> patch   // 深拷贝并剔除 undefined
```

规则：
- 未知 op → `invalid-op`；`update` 缺 `nodeId` → `invalid-op`；`create` 缺 `type` → `invalid-op`；
- 颜色非法 → `invalid-op`；`width/height<=0` → `invalid-op`；`radius` 数组长度不是 4 → `invalid-op`；
- `layout.mode` 不是 `HORIZONTAL|VERTICAL` → `invalid-op`；
- 只透传第 2.1 节列出的字段，未知字段丢弃；`op` 里允许 `label?`（仅用于日志，不下发）。
- 合法时返回规范化后的 ops（颜色保留原字符串亦可，Host 只做校验，插件侧再转 Figma 颜色对象）。

`tests/ops.test.mjs`：覆盖以上每条规则 + 一个复杂嵌套 create + dryRun 计划统计。

> 口径说明：Host 侧 `summarizePlan` 统计**顶层 op 条数**（嵌套节点数写在 description 里），工具的返回字段名为 `hostPlan`；插件侧 `apply{dryRun:true}` 的 `plan.willCreate` 统计**实际节点数**，位于 `result.value.plan`。两者不冲突，模型以插件侧为准。

## 6. 桥与本机约束（Lead 实现，供参考）

- 端口 `3977`，候选 3977–3986；manifest `devAllowedDomains` 只能写 `http://localhost:<port>`（不能带路径、不能写 IP）。
- 插件 UI fetch `http://localhost:<port>/bridge/...`；`Origin: null`，服务端 `Access-Control-Allow-Origin: *`。
- token 持久化在 `<DSH_HOME>/figma-designer/pair.json`（0600），桥重启复用同一 token。
- 会话绑定：`exec.agent.session.id` → connectionId；单个连接自动绑定，多连接需 `figma_select`。
