# v0.8.0 — 参考图与素材管线

不依赖 oil_ui_media / oil_ui_image，做成插件自己的两个工具。

## `figma_designer_reference`

```js
figma_designer_reference({
  path: 'references/linear-pricing.png',
  name: 'Linear pricing',
  place: false
})
```

- 读取本地 PNG/JPEG/GIF，返回真实尺寸、文件信息和图片附件给模型分析；
- `place:true` 时在 Figma 中创建 `Reference / <name>` 图片框，可选 `x/y/parentId/width/height/fit`；
- `place:false` 默认不修改 Figma，适合先看参考图。

用法：

1. `figma_designer_reference` 看真实参考图；
2. 拆构图、字体、色彩、间距、控件语法；
3. 写方向卡；
4. 用 `figma_designer_compare` 验证多个方向。

## `figma_designer_asset`

```js
figma_designer_asset({ path: 'assets/hero.jpg', name: 'Hero image', x: 0, y: 0 })
figma_designer_asset({ path: 'assets/avatar.png', nodeId: '11:42' }) // 替换已有节点的 image fill
```

- 新建图片框，或给已有节点设置 image fill；
- 支持 PNG/JPEG/GIF；默认 FIT，可传 FILL；
- 返回 Figma node id 和图片预览；
- 不调用外部素材工具，素材由用户/设计师提供本地文件。

## 设计流程

- 参考图只用于提取关系，不照搬业务内容；
- 素材是设计的一部分，不要用通用渐变/几何图形替代必要图片；
- 图片进入 Figma 后再截图检查，不在图片查看器里判断。

## 边界

- 不做联网搜索、不生成图片、不做素材授权管理；
- 只支持本地 PNG/JPEG/GIF；
- 参考图尺寸/比例需要模型结合视觉判断，工具只给真实像素信息；
- 图片填充节点仍可被后续 `figma_designer_apply` 调整位置/尺寸。
