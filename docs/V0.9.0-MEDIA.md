# v0.9.0 — 原生图库搜索与图片落地

插件自己的素材管线，不依赖 oil_ui_media / oil_ui_image。

## 1. `ui_media`：搜图 → 选图 → 下载

```js
ui_media({ action: 'search', query: 'minimal workspace desk', source: 'all', limit: 6 })
ui_media({ action: 'fetch', refs: ['O2', 'C4'], dir: 'assets/media' })
```

### search

- 来源：Openverse、Wikimedia Commons、Met、Art Institute of Chicago、Cleveland Museum of Art、NASA、Poly Haven
- 返回：编号、标题、作者、许可证、来源页、尺寸、可商用判断
- 下载缩略图并生成 `.ui-media/contact.html` 联系表
- 图片附件直接返回给模型看

### fetch

- 按 ref 下载原图到 `assets/media`
- 校验 PNG/JPEG/GIF
- 写入 `SOURCES.md`（来源、许可、署名）
- “仅参考/需核对”的许可证默认拒绝，需 `acceptLicense:true`

## 2. `ui_image`：放进 Figma

```js
ui_image({ path: 'assets/media/O2-minimal-desk.jpg', x: 0, y: 0 })
ui_image({ path: 'assets/media/C4-plant.png', nodeId: '11:42' }) // 替换 image fill
```

- 新建图片框
- 或替换已有节点的 image fill
- 支持 FIT/FILL
- 等价于原 `figma_asset`，`ui_` 命名作为素材管线入口

## 版权规则

- 只把 `usable:'page'` 的候选默认放进页面
- CC BY / BY-SA 需按 `attribution` 署名
- CC0 / Public Domain 也建议记录来源
- `reference` 只能做参考，不能直接进入商用设计
- `check` 默认拒绝，需人工确认
- `SOURCES.md` 是交付的一部分，不要删除

## 边界

- 网络搜索和下载在 Host 完成，Figma iframe 仍只访问 localhost
- 不做图片生成；只做开放图库检索和本地图片落地
- 不支持 WebP（Figma 放置只接收 PNG/JPEG/GIF）
- 搜索结果依赖上游 API；某个来源失败时返回 warnings，不阻塞其他来源
