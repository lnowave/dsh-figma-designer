# v0.5.0 — token-aware HTML/JSX export

`figma_export` 的 `html` / `jsx` 现在默认读取设计系统，并把 Figma Variables / Paint Styles / Text Styles 映射为 CSS 变量和文本样式 class。

## 用法

```js
figma_export({ format: 'html', target: 'node', nodeIds: ['11:606'] })
figma_export({ format: 'jsx', target: 'selection' })
figma_export({ format: 'html', tokenAware: false }) // 需要原始值时
```

## 产物

HTML：

```html
<style>
  :root {
    --color-primary: #F97316;
    --space-16: 16px;
    --paint-brand-primary: #F97316;
  }
  .text-heading-xl { font-family: ..., font-size: 48px; ... }
</style>
<div style="background: var(--paint-brand-primary); gap: var(--space-16); ...">
```

JSX 同理：`styles.css` 顶部包含 token CSS 与 `.text-*` 类，`App.jsx` 的节点 class 会带上文本样式 class。

## 匹配顺序

1. 节点显式绑定的 style id（`fillStyleId` / `textStyleId` 等）；
2. 节点 `boundVariables` 指向的 Variable id；
3. 颜色/字号/间距值匹配设计系统里的 token；
4. 都没有 → 原始 hex / px，不丢样式。

## 支持范围

- 颜色：背景、文字、描边 → `var(--...)`；
- 文本：Text Style → `.text-*` 类（字体/字号/字重/行高/字距）；
- 间距：auto layout 的 itemSpacing / padding → `var(--space-*)`；
- 圆角：float variable（名称含 radius/corner）→ `var(--...)`；
- 不替换：width/height、阴影/effect、渐变/图片，仍按原值输出。

## 降级

- 没有设计系统 / 读取失败 / token 不可用时，自动回退到 v0.4 的原始值输出，并返回 warning；
- `tokenAware:false` 可显式关闭。

## 已知边界

- 组件实例仍展开为图层，尚未生成 React 组件边界（后续版本）；
- 一个节点只映射一个文本样式；富文本 runs 不拆分；
- token 值匹配是近似匹配，精确绑定以 style id / bound variable 为准；
- 导出的 CSS 变量来自 `figma_library` 当前默认 mode，不处理多 mode 切换。
