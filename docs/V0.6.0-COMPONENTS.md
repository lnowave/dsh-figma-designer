# v0.6.0 — component-aware JSX 导出

`figma_export` 的 `jsx` 默认把 Figma 组件实例提取成 React 组件，而不是全部展开成 div。

## 用法

```js
figma_export({ format: 'jsx', target: 'selection' })
figma_export({ format: 'jsx', componentAware: false }) // 关闭，回到展开模式
```

## 产物

```text
App.jsx        引用提取出的组件
components.jsx 每个组件一个导出函数
styles.css     组件与页面共用样式 + token CSS
```

示例：

```jsx
import './styles.css'
import { SizeLargeStateDefault, SizeSmallStateDefault } from './components.jsx'

export default function App() {
  return (
    <div className="figma-root ...">
      <div className="component-slot-...">
        <SizeLargeStateDefault />
      </div>
      ...
    </div>
  )
}
```

## 提取规则

- 只扫描当前导出根节点下的 **INSTANCE**；
- 按实例的组件 id + 变体名 + 子树视觉/文字/布局指纹分组；
- **指纹相同**的实例复用一个组件；不同文字/颜色/尺寸等 override 会生成不同组件（暂不提升为 props）；
- 组件根保留实例的尺寸、填充、描边、文本、布局；外层 `component-slot` 负责父级中的定位/尺寸；
- 组件内部的嵌套实例暂按展开模式处理（不递归生成子组件）。

## 边界

- 当前是“组件快照提取”，不是完整的 props/variant API 生成；
- 不同 label 的同一组件会生成两个组件，而不是一个接受 label prop 的组件；
- 组件内部的自定义字体/图标仍受 v0.2 导出限制（VECTOR 图标占位）；
- 组件实例的 `componentSet` / property definitions 还没有映射为 React props（后续可做）；
- HTML 导出仍为展开结构；component-aware 只作用于 JSX。
