# v0.6.1 — 组件 variant 映射为 React props

在 v0.6 component-aware 基础上，把同一组件集的多个 variant 收敛成一个 React 组件，并用 props 选择变体。

## 用法

```js
figma_export({ format: 'jsx', componentAware: true })
```

## 产物

```text
components.jsx
  SizeLargeStateDefault()  // 各 variant 快照
  SizeSmallStateDefault()
  Button({ size = "Large", state = "Default" }) // 变体包装组件
App.jsx
  <Button size="Large" state="Default" />
  <Button size="Small" state="Default" />
```

## 规则

- 实例按 `componentSetId` / `componentSetName` 聚合；
- 从组件名解析 `Size=Large, State=Default` 这样的 variant；
- 属性名 camelCase：`size` / `state`；默认值取第一个 variant；
- 每个 variant 仍保留独立快照函数，包装组件按 props 选择；
- 包装组件只在“每个 variant 唯一”时生成；同一 variant 有多个不同内容快照时回退为独立组件，避免错配；
- 组件集没有 `componentSetName`/variant 信息时保持 v0.6 组件快照。

## 边界

- 当前只映射 **variant 属性**，不映射 text/fill 等 instance overrides 为 props；
- 同一 variant 多个 label 仍会生成多个快照组件，不会自动合并为一个 `label` prop；
- 嵌套实例仍展开；
- 组件内 VECTOR 图标仍受导出限制。
