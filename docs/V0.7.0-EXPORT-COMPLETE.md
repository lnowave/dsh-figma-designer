# v0.7.0 — 导出完整性收口

这一版把导出里必须补齐的能力一次补齐，之后把精力转回设计质量。

## 1. 组件文本 overrides → props

组件函数现在会为内部文字生成 props：

```jsx
export function Button({ label = "Sign in" } = {}) {
  return <div ...><div ...>{label}</div></div>
}
```

不同 label 的实例共用一个组件，不再拆成多个快照。variant 包装组件会把 `label` 透传给对应 variant。

## 2. 同变体的不同文本合并

组件分组时忽略文本内容、保留视觉/布局指纹：

- 同一 variant 的不同 label 进入同一组；
- 没有 variant 的同一组件也按视觉/布局合并；
- 只在实际视觉/布局不同时才拆组件。

## 3. VECTOR 图标导出

tree 会异步导出 VECTOR 节点的 SVG（`svgBase64`），HTML/JSX 渲染为内联 SVG 图片，而不是空占位盒子：

```html
<div class="google-icon-..."><img class="figma-svg" src="data:image/svg+xml;base64,..." /></div>
```

Google/GitHub 图标等不再是空框。

## 4. 隐藏节点不导出

`visible:false` 的子节点直接从导出结果中跳过，不再输出 `display:none` 的壳。

## 5. 与 token-aware / component-aware 组合

- token-aware 仍作用于组件、变体、文本样式；
- component-aware + variant props + text props 可同时开启；
- 组件内部 VECTOR 图标也会导出 SVG。

## 边界

- 仍未把 fill/stroke/visibility 等 instance overrides 提升为 props；
- 组件内部嵌套实例仍展开；
- 图片填充、渐变、多 mode Variables 仍未完整支持；
- 组件名来自 variant/set 名，命名可能偏长。
