# v0.4.1 — figma_designer_audit

只读设计质量审计。输入选区/页面/节点，读取完整样式树 + 设计系统，返回 0–100 分和可定位到 `nodeId` 的问题清单。

## 工具

```js
figma_designer_audit({ target: 'selection' })
figma_designer_audit({ target: 'page', maxNodes: 800 })
figma_designer_audit({ target: 'node', nodeIds: ['11:606'] })
```

不修改画布；不会触发写入屏障。

## 检查项

| 类别 | 规则 |
|---|---|
| 对比度 | 文字前景 vs 继承的祖先纯色背景；正文 4.5:1，大字 3:1；渐变/图片背景跳过并计入 skipped |
| 字号 | <10px 错误，<12px 警告 |
| 行高 | 多行文本行高 / 字号 <1.4 警告 |
| 内容 | 检测 lorem/placeholder/示例/标题/描述/待定等占位文案 |
| 间距 | 收集 auto layout 的 itemSpacing / padding；非 4px 网格、值过多警告 |
| 颜色 | 纯色数量 >12 警告，>20 错误；与已有 Paint Style/Variable 颜色计算 token 匹配率 |
| 点击区 | 名称匹配 button/icon/tab/... 的 frame/instance/component，小于 44×44 警告 |
| 裁剪 | `clipsContent:true` 的父级中越界子节点 |
| 组件 | 统计组件实例/组件/手绘 frame；无实例时给提示 |
| 截断 | tree 节点数超限时标记 `truncated` |

## 使用建议

1. 设计前：`figma_designer_audit` 摸现有页面基线；
2. 设计后：先修 `error`，再处理高影响 `warn`；
3. 审计通过后再交给独立评审（审计只能查客观项，不能判断方向/品味/动效）；
4. `figma_designer_audit` 不替代 `reviewer.md` 的 1–10 分独立评审。

## 边界

- 对比度只处理纯色背景；渐变/图片/视频背景跳过，避免误报；
- 不检查焦点/错误/加载/动效等运行时状态；
- 颜色 token 覆盖按颜色值匹配，不等同于“已绑定变量”；
- 分数是问题的加权汇总，不是审美评分。
